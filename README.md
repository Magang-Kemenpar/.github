## 📄 Description

Dashboard Database Kementerian Pariwisata (Kemenpar) ini dikembangkan sebagai pusat informasi terpadu untuk memonitor, mengelola, dan memvisualisasikan data strategis pengembangan pariwisata nasional. 

Fokus utama dari sistem ini adalah pelacakan performa dan potensi pada **10 Destinasi Pariwisata Prioritas (DPP)** dan **3 Destinasi Pariwisata Regional (DPR)**. Selain itu, dashboard ini juga mengintegrasikan pemantauan seluruh **Program Kegiatan Deputi 1 (Bidang Sumber Daya Kelembagaan)**, memastikan setiap inisiatif kelembagaan dan pengembangan SDM terekam dengan baik. Melalui integrasi data ini, kami bertujuan mendukung proses pengambilan keputusan yang lebih cepat, akurat, dan berbasis data (*data-driven*) di lingkungan Kemenpar.
